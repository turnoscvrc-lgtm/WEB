# CVRC — Clínica Veterinaria Rafael Calzada

Sitio web institucional de la Clínica Veterinaria Rafael Calzada, Buenos Aires, Argentina.

## Contenido
- Información institucional.
- Especialidades veterinarias.
- Servicios de Cardiología Veterinaria.
- Datos de contacto, ubicación y horarios de atención.
- Acceso directo a WhatsApp y llamadas telefónicas.

## Publicación
Sitio web estático desarrollado en HTML, CSS y JavaScript, preparado para publicarse mediante GitHub Pages.
